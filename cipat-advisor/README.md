This module contains the **CIPAT Botanical Expert Reasoning System** for the EcoDrip ecosystem, developed by **DHRUV PATEL**.

## 📌 Features

- **Prolog Symbolic Reasoning Engine:** Powered by Tau-Prolog to evaluate plant diseases, nutrient deficiencies, and environmental thresholds deterministically.
- **AI Plant Health Diagnostic Assistant:** Seamless bridge between deterministic agronomic rules and Google Gemini multi-modal vision models.
- **Knowledge Base Rules:** Comprehensive botanical logic repository covering soil health, irrigation schedules, and crop profiles.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```
